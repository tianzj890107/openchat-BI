# SC01-SC05 场景与可回答范围

## 场景表

| 场景 | 中文 | 典型问题 | 主要对象 |
| --- | --- | --- | --- |
| `SC01` | 发货超期治理 | 哪些订单超期未发、超期多久、为什么、怎么处置、复验 | 订单、订单行、交期、发货单 |
| `SC02` | 红区报价治理 | 红区报价有多少、集中在哪里、占比、审批是否异常 | 报价申请、价格区间、审批记录 |
| `SC03` | 战略客户突破 | 哪些战略客户没有有效商机、覆盖率缺口、待突破 | 客户、商机、目标、负责人 |
| `SC04` | 中标未签治理 | 哪些项目中标未签、等待多久、卡在什么条款 | 投标、中标、合同、条款 |
| `SC05` | 计划外发货偏差 | 哪些发货偏离日计划、如何核查、后续是否改善 | 日计划、发货、订单行、计划版本 |

## 场景识别

服务端 `Process360Route` 负责最终判定。技能侧只做粗分：

- 命中“超期未发 / 订未发 / 发货超期 / 交期 / 延期” → SC01
- 命中“红区 / 报价 / 价格区间 / 审批慢” → SC02
- 命中“战略客户 / 客户突破 / 商机 / 覆盖率” → SC03
- 命中“中标 / 未签 / 合同签订 / 投标” → SC04
- 命中“计划外发货 / 发货偏差 / 日计划 / 发货计划 / 偏离计划” → SC05

两个场景同时高分时，按 `Process360Route` 返回的 `clarification` 向用户确认，
不要自行挑一个继续。

## 可回答与不可回答

- 可回答：对象清单、金额/数量、期间对比、结构占比、异常定位、候选原因、影响测算、
  处置草稿、复验计划。
- 不可回答：发运/签单/调价等业务写操作；没有对象键/批次轨迹时的流程转化率；
  没有批准目标时的关闭结论；数据库不存在的字段或口径。
- `SC02` 缺价格区间映射、`SC05` 同一订单行存在多计划版本时，服务端返回 `blocked`。
  这表示口径未闭环，不是“没有风险”，也不允许换用通用指标补数。

## 场景与 SOP

| 场景 | 常见 SOP |
| --- | --- |
| SC01 | P03 事实、P06 异常、P09 根因、P10 方案、P15 复验 |
| SC02 | P03、P05 结构、P06 异常 |
| SC03 | P03、P05、P06 |
| SC04 | P03、P06、P09 |
| SC05 | P03、P06、P09、P15 |

用户明确要风险卡/待办/改善方案时，计划会追加 P09 与 P11，最终停在
`Process360Draft`，由用户点击后下发。
