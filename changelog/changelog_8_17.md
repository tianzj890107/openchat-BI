# openchat-BI 变更记录（2026-08-17）

> 本文档只记录 2026-08-17 当天完成的最终变更。

## 维护规则

- 今天的变更只追加到本文档，不写入其他 changelog。
- 每次发布或一组相关修改合并为一条记录，不记录中间尝试。
- 每条记录说明用户可见变化、涉及页面/场景和主要文件。
- 未完成、被回滚或未验证的事项不要写成已完成。

## 2026-08-17

今天的 changelog 已启用。后续今天完成的修改将持续同步到本文件，并按最终功能状态合并记录。

### 统一使用 Pro UI 默认图表组件

- 重新从 Pro UI 静态资源获取新版 UMD，接入 `ProBarChart`、`ProHorizontalBarChart`、`ProLineChart`、`ProAreaChart` 和新增的 `ProPieChart`。
- 会话图表、历史会话图表、看板图表及多维图表统一通过 Pro UI 默认组件渲染，保留历史恢复、看板、导出、维度切换、标题、数据来源和口径说明；不再传入此前的颜色、条宽或 `grid` 覆盖。
- 主要文件：`frontend/src/runtime.js`、`frontend/public/lib/`、`bi_agent/web/static/index.html`。
### 导航栏两级折叠

- 导航栏支持“完全隐藏 → 仅图标 → 完全展开”的两级展开路径；完全隐藏时保留固定在左侧的折叠按钮，按钮图标始终向左。
- 完整导航点击折叠后直接隐藏；重新展开第一次恢复图标栏，第二次恢复完整文字导航。
### 完全隐藏状态按钮方向修正

- 完全隐藏导航栏时，左侧恢复按钮改为向右箭头；仅图标状态下的折叠按钮继续使用向左箭头。
### 仅图标状态按钮方向修正

- 仅图标状态的导航按钮改为向右箭头；完整展开状态仍显示向左折叠箭头，完全隐藏状态的恢复按钮也保持向右。
### 会话与看板标题居中

- 将“对话”标题改为“会话”并与“看板”一起居中显示；隐藏会话回合数和看板数量提示，保留后台计数节点以维持现有逻辑。
### 完全隐藏状态恢复按钮嵌入标题行

- 将完全隐藏导航栏时的向右恢复按钮嵌入会话标题行左侧，按钮高度与 34px 标题行保持一致，不再显示为独立悬浮方块。
### 竖屏会话/看板切换

- 增加页面尺寸检测：当宽度小于高度时，会话和看板不再同时显示，改为标题行按钮单页切换；横屏仍保持会话与看板并排显示。
- 竖屏下隐藏看板折叠/展开控件，避免与会话/看板切换逻辑混用。
### 竖屏自动隐藏功能栏

- 竖屏检测生效时，左侧功能栏自动进入完全隐藏状态；切回横屏后恢复为仅图标状态，保持与会话/看板单页切换一致。
### 展开按钮样式恢复

- 恢复完全隐藏状态展开按钮原有的边框、圆角和白底蓝色样式；仅保留嵌入标题行所需的 34px 尺寸和左侧位置变化。
### 竖屏看板按钮位置修正

- 保留看板“清空”按钮；仅在竖屏显示看板时，将其定位到“会话”切换按钮左侧，避免两个按钮重合。
### 竖屏清空按钮显示修正

- 强制确保竖屏看板页的“清空”按钮可见，并固定在“会话”切换按钮左侧，避免被通用按钮布局规则隐藏。
### 会话/看板布局改为地址参数

- 移除宽高比自动判断；通过 `?layout=two` 使用两栏并排布局，通过 `?layout=one` 使用一栏会话/看板切换布局。
- 未传布局参数默认两栏；一栏模式下功能栏自动完全隐藏，切换布局只响应地址路由变化。
### 布局参数重定向保留

- 修正首页跳转到 `/workbench` 时丢失查询参数的问题，现在访问 `/?layout=one` 会正确保留为 `/workbench?layout=one`。

### 表格滚动条细化

- 将表格区域的横向和纵向滚动条调整为 6px，并保持页面其他滚动区域样式不变。

### 用户选择提交状态修正

- 选择接口成功接受后立即将卡片显示为“已提交”，统一使用绿色状态样式；继续执行期间不再在选择卡片下方重复显示“思考中”。失败时仍恢复为可重试状态。
- 已将绿色范围收窄为仅替换提交后原橙色边框，卡片背景、正文、选项和按钮表面恢复原有样式。
- 提交完成后的“需要您选择”标签改为绿色，“已提交”按钮改为绿色背景和白色文字。
- “已选择”状态行前的箭头在提交完成后改为绿色。

### 单栏看板显示工作流

- 仅在 `layout=one` 的单栏模式下，为看板增加“分析 SOP”和“任务清单”；切换到看板时默认折叠，双栏模式保持原有看板布局不变。

### 会话与看板滚动联动

- `layout=one` 和 `layout=two` 均启用会话与看板的双向滚动同步；滚动任一侧时按内容进度同步另一侧，任务清单点击定位逻辑继续保留。

### 看板图表尺寸与会话统一

- 看板普通图表和多维图表改用与会话图表相同的画布高度，避免看板中的 Pro UI 图表被压缩显示得过小。

### 图表标题与卡片层级统一

- 图表标题改由 Pro UI 图表组件内部渲染，移除会话和看板外层重复标题；保存链接等元信息保留在图表卡片外侧，图表结果只保留单层可见边框。

### 历史图表外层气泡清理

- 历史会话中已保存的图表同步移除旧的 Ant Design 外层结果气泡和标题栏，恢复为 Pro UI 单层图表；`saved: chart-...html` 元信息保留在气泡外侧。

### 单栏模式侧栏展开按钮优化

- `layout=one` 下左上角侧栏展开按钮移除边框，并将图标放大至原来的 1.2 倍；其他布局保持不变。

### 单栏模式会话面板铺满

- `layout=one` 下移除会话面板外层边框、圆角和阴影，使会话区域直接铺满可用页面空间；双栏布局保持原样。
