
## 二、`ontology-agent` 的实际调用

主要实现文件：`../ontology-agent/open-claude/oc_codex_server.py`。

### 1. 获取智能建模上下文

```http
GET /intelligent/modeling/tasks/{taskCode}/execution-context
```

由 `fetch_execution_context()` 和 `_handle_mission_task()` 调用，触发于进入建模任务、查看任务信息、发送任务消息以及上传建模结果前。

### 2. 获取消歧整合上下文

```http
GET /intelligent/integration/tasks/{taskCode}/execution-context
```

根据显式 `taskType` 或任务编码前缀判断调用 `modeling` 还是 `integration`。

### 3. 回调智能建模结果

```http
POST /intelligent/modeling/tasks/{taskCode}/callback
```

调用链：

```text
前端上传结果文件
→ /api/minio/upload
→ FileServer 上传 CSV
→ _callback_after_upload()
→ ontology_task_callback()
→ Ontology callback 接口
```

回调前会校验 `expectedFiles`、解析要素、CSV 表头和结果文件完整性。

### 4. 回调消歧整合结果

```http
POST /intelligent/integration/tasks/{taskCode}/callback
```

整合任务会先上传结果文件，确认所有 `expectedFiles` 和 `ok.csv` 都存在后再回调，整合回调本身不携带 `files`。

### 5. 任务接口使用的请求头

```http
X-App-Id
X-Ontology-Repository-Id
X-User-Id
```

Ontology 网关基地址由 `ONTOLOGY_API_BASE` 或配置文件决定，代码默认值为：

```text
http://pdt-dev.eimos.com/api/gateway2/ontology
```

## 三、`openchat-BI` 的实际调用

### 1. Doris 查询

```http
POST /agent/doris/query
```

由以下 Agent 工具触发：

- `SQLRun`
- `ListTables`
- `DescribeTable`

调用链：

```text
用户问题
→ SQLRun / ListTables / DescribeTable
→ DorisHttpConn
→ POST /agent/doris/query
```

请求体为：

```json
{"sql": "SELECT ..."}
```

默认地址：

```text
http://172.16.5.181:30834/agent/doris/query
```

默认数据库：

```text
ontology_demometaerp_scm_po
```

### 2. 查询本体库列表

```http
GET /system/manager/ontology-repository?page=1&size=100
```

调用链：

```text
打开“数据源”或“本体适配”
→ GET /api/sources
→ RemoteOntologyClient.list_repositories()
→ GET /system/manager/ontology-repository
```

该接口用于获取：

- 本体库名称；
- repository ID；
- `dorisDatabase`；
- 描述信息。

### 3. 当前智能分析使用的其他本体接口

这些接口不在两份任务接口文档中，但会被 `openchat-BI` 的智能分析实际调用：

```http
POST /agent/ontology/ensureOntologyObject
GET  /agent/ontology/findRelatedObjects
POST /agent/ontology/scriptQuery
```

对应工具包括：

- `OntologyQuery`
- `TermDisambiguate`
- `MetricLookup`
- `RelationLookup`
- `EntityDescribe`
- `ListBusinessObjects`
- `GraphContext`
- `GraphExpand`

## 四、当前未实际调用的接口

以下接口在两个项目中没有发现实际网络调用：

```http
GET /system/manager/ontology-repository/{repositoryId}
```

`openchat-BI` 中虽然有 `RemoteOntologyClient.repository_info()` 方法，但没有调用方。当前界面主要使用本体库列表接口返回的 `dorisDatabase`，不会再次请求详情接口。

## 五、额外的文件服务调用

`ontology-agent` 上传建模和整合结果时还会调用 FileServer：

```http
POST /sdk/object/put
```

调用链：

```text
CSV 结果文件
→ FileServer /sdk/object/put
→ 获取 objectKey / previewUrl
→ 回调 Ontology 后端
```
