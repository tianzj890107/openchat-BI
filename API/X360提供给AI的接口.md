# X360提供给AI的接口

> 如果不需要任务（tasks）信息，可联系 $\color{#0089FF}{@李泽丰}$ 删除。

## 1. 按流程定义 ID 查询（AI 视图）

*   **Method**：`GET`
    
*   **Path**：`/api/gateway2/x360/v1/process-definitions/ai/{bpProcessDefinitionId}`
    
*   **Path 参数**：
    

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `bpProcessDefinitionId` | Long | 是 | 流程定义 ID |

*   **Query 参数**：无
    
*   **请求体**：无（GET）
    
*   **请求示例**：`GET /api/gateway2/x360/v1/process-definitions/ai/{{流程定义ID}}`

## 2. 按流程定义 KEY 查询（AI 视图）

*   **Method**：`GET`
    
*   **Path**：`/api/gateway2/x360/v1/process-definitions/ai/key/{processDefinitionKey}`
    
*   **Path 参数**：
    

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `processDefinitionKey` | String | 是 | 流程定义编码 |

*   **Query 参数**：无
    
*   **请求体**：无（GET）
    
*   **请求示例**：`GET /api/gateway2/x360/v1/process-definitions/ai/key/{{流程定义KEY}}`
    

### 返回体 `data` 结构

与接口 1 完全一致（即 `AiProcessDefinitionDTO`），结构同上。
