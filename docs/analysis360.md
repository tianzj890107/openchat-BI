# 360 智能分析

360 智能分析是独立于通用「智能分析」（openchat BI 本体）的一项能力：它工作在
《亿纬锂能_流程360全局本体_无投标_V1.0》之上，按《流程360全局本体_智能分析Agent访问策略_V1.0》
执行，保留六步 SOP。它也不同于 `process360-analytics-skill`（SC01–SC05 五个治理场景的 MCP 技能）。

## 三者的区别

| 能力 | 本体 | 入口 | Agent |
| --- | --- | --- | --- |
| 智能分析 | 通用经营 / 财务本体 | 工作台直接提问 | `bi-analyst` |
| 360 智能分析 | 流程360全局本体 | 穿透式分析卡片的「深度分析」 | `analysis360` |
| 卡片判定 | 各卡片自己的节点本体 | 驾驶舱固定年度分析 | 规则优先 + 模型逐条判定 |

卡片上的风险、问题、根因来自卡片的节点本体。点击「深度分析」只带走条款本身
（编码、名称、描述、等级、期间和所引数值），不带走卡片本体；360 智能分析把条款重新定位到
全局本体。卡片自有的编码（例如共同问题卡片的 `IS01`）在全局本体中不存在时，只按名称给出候选，
由用户确认，不硬套。

## 交接流程

1. 卡片每条风险、问题、根因后面有「深度分析」按钮；建议没有。
2. 点击后，条款上下文 `POST /api/analysis360/handoff`，服务端返回交接编号。
3. 新标签页打开 `…/workbench?a360=<编号>`。`static/analysis360-handoff.mjs` 让这个页面的第一条
   聊天请求带上编号；服务端把该页面的会话建成 360 会话，并以条款作为第一轮输入。
4. 第一轮只做三件事然后停下：定位范围 → 列出带入的条款及其在全局本体中的对应 → 询问用户。
   - 风险 / 问题：询问是否下钻根因。
   - 根因：让用户选择「继续提问下钻」或「给出对应建议」。
5. 该标签页之后的每一轮都在 360 会话中；其他标签页仍是通用智能分析。

交接内容只存在服务进程内存中，6 小时失效；失效后回到卡片重新点击即可。

## 工具（访问策略的六个接口）

| 工具 | 策略接口 | SOP 步骤 |
| --- | --- | --- |
| `G360ResolveScope` | resolve_scope | 意图识别 |
| `G360GetSubgraph` | get_subgraph | 本体模型匹配 |
| `G360ExecuteQuery` | execute_query | 数据获取和可视化 |
| `G360DrillRelation` | drill_relation | 数据获取和可视化 |
| `G360EvaluateAndRecord` | evaluate_and_record | 根因分析 |
| `G360DraftAndRecheck` | draft_and_recheck | 决策行动 |

服务端强制的约束：

- 只执行全局本体「查询注册」中登记的 SQL，模型不能提交 SQL、表名或自造证据编号。
- SQL 原文按分片拼接并校验登记的 SHA-256；T 模板绑定 `parameters` 中的期间和观察日，
  Q 配置查询按筛选契约保留或删除 `FILTER_BEGIN/END`、`TIME_BEGIN/END` 块。
- 依赖 MOCK 配置的查询和待验收的 N 类诊断查询一律阻断，返回原因。
- 查询必须属于当前范围的子图；每个范围最多 12 次查询，每个结果预览 100 行，实体下钻最多 3 跳。
- 实体下钻只走已验收的关系，主键必须来自上一步证据；「CRM引用候选」类关系被拒绝。
- 评估状态为 成立 / 未命中 / 待核实 / 无法判定 / 不适用 / 未评估。成立和未命中必须引用本次分析的
  证据；无法判定必须写明缺什么；被截断的证据不能用来判定成立或未命中。
- 建议只是草稿：成立的根因给改进措施，其余只给核查措施；任务令由责任人确认后下发。

## 配置

```text
docs/亿纬锂能/亿纬锂能_流程360全局本体_无投标_V1.0.xlsx
  → python scripts/build_analysis360_config.py
  → bi_agent/analysis360/assets/global-ontology.json
```

全局本体更新后重新运行构建脚本。数据库沿用驾驶舱的只读连接（`PROCESS360_PG_*`，
回退 `WORKBENCH_PG_*`）。

## 当前限制

- 没有接入按组织、客户的行级权限（ABAC）：范围是服务只读账号的可见范围，工具返回中有说明。
- 评估记录和证据保存在会话内存中，没有写入 `ywln_ai` 的 RUN01–RUN10 实例表。
- 从历史记录恢复的会话回到通用智能分析；360 会话只在点击「深度分析」打开的标签页内延续。
- 工作台前端没有重新构建：页面仍显示通用智能分析的欢迎语和「智能分析」字样，仅标签页标题改为
  「360 智能分析」。
