# Spec：服务器引用统一使用 IP 地址

状态：Implemented / TDD Green（修订于 2026-09-08）

## 目标

仓库内不再依赖或描述任何本机 SSH Host 别名。凡需指明当前测试服务器时，统一直接使用
`172.16.10.34`；命令使用 `ssh 172.16.10.34`，不得假设某台开发机存在额外 SSH config。

## 范围

- 源码、脚本、测试、Spec、README、部署文档、版本文档与 changelog；
- 活动文档和历史记录中的服务器称谓都统一；历史事实、日期、端口和版本状态不得改变；
- 分析仓库的服务器环境变量同步测试直接连接 IP；
- 仅替换服务器引用，不修改远程文件、不重启服务、不部署。

## 验收

`tests/test_literal_ip_server_references.py` 对所有 Git 跟踪文件执行大小写不敏感扫描，并验证
需要 SSH 连接的活动测试直接包含 IP。Red 阶段必须命中既有别名引用，实现后扫描为零。
