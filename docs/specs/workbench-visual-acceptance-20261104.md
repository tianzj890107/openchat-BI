# Workbench 视觉与交互验收（2026-11-04）

- 延用 Pro UI 组件及当前品牌色，优先整理信息层级和布局。
- 新访客默认收起空结果面板；保留用户明确的展开/收起选择，结果和展开入口始终可访问。
- 无分析进度时不显示空 SOP；有进度时使用真实后端事件，不虚构状态。
- 欢迎页不重复版本和产品长名；推荐问题一行一项，不重复说明文字。
- 收起看板时，对话和输入区保持适当阅读宽度；窄屏不得横向溢出，输入区始终可达。
- 图标按钮有可访问名称。保留历史、数据源、模型和业务流程，不删除数据或自动发送问题。
- 验证：浏览器桌面/窄屏截图、设置页面导航、输入与清空、提示填入、看板开关、控制台异常。

- 密钥清除必须有明确图标和二次确认；本轮无需执行阶段不得被标记为已中止。
