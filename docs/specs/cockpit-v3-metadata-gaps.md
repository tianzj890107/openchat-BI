## 渲染方式

页面不再使用原型 DOM/CSS 快照，也不再按原型尺寸保留空位。渲染路径为：

1. `metadata.py` 编译 `iba-demo/feature/demo_1021` commit `17152091ffce520d1e05a419c4192f7762db4b26` 的页面、模板、组件和绑定。
2. `runtime.py` 把可渲染组件和冻结演示数据写入 `static/cockpit/metadata/runtime.json`。
3. 浏览器用 `ProBiDashboard` 渲染页面组件，用 `templateRegistry` 加载模板；卡片、图例、标题栏、表格工具栏和按钮均采用 ProUI 组件自身样式。
4. 绑定组件使用 `dataConfig.mockData`，不调用 AP、本体或生产数据库。
5. 运行包不注入自定义替身组件；缺失子组件保持空位，不补近似卡片。
