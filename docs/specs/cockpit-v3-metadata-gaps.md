# V3 原型、交付元数据与页面差异（2026-10-22）

## 当前页面边界

- `/cockpit/overview`：全局经营看板，支持 `?id=1|2&metric=sales|volume` 查看原型年度图表视图。
- `/cockpit/operations`：运营 360 整体分析，支持 `?id=1|2&stage=opportunity|guidance|quotation|technical|bid|order|shipment`。
- `/cockpit/analysis`：穿透式问题分析，支持 `?id=1|2&stage=opportunity|bid|order|shipment`。
- `/cockpit` 以 `307` 跳到 `/cockpit/overview`。
- 三页只加载看板本体；顶部保留四个驾驶舱视图 Tab：首页、全局经营看板、运营 360 整体分析、穿透式问题分析。
  不渲染左侧工作区、会话区、宿主页面标题或外层筛选栏。页面之间的业务入口仍保留在看板内部，所有 Tab 和跳转保留当前 `id`。

## 对照基线

- 原型：`V3-总裁驾驶舱.html`，SHA-256 `8faad500847468d61c279bcab1f6212ce3e521d25bb0743f307621da39303329`。
- 交付元数据：`iba-demo/feature/demo_1021` commit `17152091ffce520d1e05a419c4192f7762db4b26`；2 个根组件、14 个子模板、130 项组件配置、16 个声明式插槽。
- 源 JSON 与 `insights.js` 冻结于 `static/cockpit/metadata/iba-demo-1021/`；运行适配与差异记录在 `bi_agent/cockpit/metadata.py`，可由 `GET /api/cockpit/metadata` 查看。
- 原型数据基线：`bi_agent/cockpit/fixtures/v3-prototype.json` 与 `PrototypeSource`。

## 布局对齐方式

交付元数据没有提供与原型一致的卡片宽高、DOM 层级、按钮排列和主题，因此不能把 ProUI 的近似画布当成逐项一致。当前实现使用原型自身的看板 DOM 与样式快照作为布局基线：

- `static/cockpit/layout/views.json`：从原型渲染函数捕获的 15 个看板视图，记录原型哈希、视图 HTML、119 个缺失空位及原始宽高。
- `static/cockpit/layout/prototype.css`：原型内联样式快照。
- `static/cockpit/metadata/runtime.json`：由 `bi_agent/cockpit/runtime.py` 和 `scripts/export_cockpit_runtime.py` 生成的静态 ProUI 运行包，包含 7 个可挂载组件、其绑定数据和 19 个视图挂载点。8876 纯静态站不依赖 `/api`。
- `scripts/extract_cockpit_layout.mjs`：可复现的 Chrome DevTools Protocol 提取脚本；移除脚本、内联事件和外部资源，只保留 DOM/CSS。
- 元数据仍用于判断交付覆盖范围和输出缺项报告；年度图和头盔图只挂载有明确 ProUI 组件和绑定数据的空位，没有为缺失配置编造近似卡片。页面底部的“原型对照”只汇总当前视图仍留空的缺项。

这意味着三页的**静态布局、卡片顺序、按钮位置和缺失区尺寸**按原型对齐；不代表所有交互、真实数据或交付组件已经齐全。

## 首页覆盖核对

交付的 `overview` 模板（`2112001069107167233`）只有 9 个组件：分组容器、标题、年度／月度按钮组、
5 张经营指标卡和 1 个指标模板占位。能够确认的元数据范围仅覆盖经营指标区，且 5 张卡的源绑定仍是
`M0001`（采购金额）／`M00013`（发货金额），与销售额、出货量、毛利率、净利率、应收周转标题不一致；
页面展示值由运行适配层显式绑定原型 fixture，不是 AP 实绩。

以下首页内容不在交付元数据中，只存在于原型 HTML／fixture：欢迎语、3 张重点风险卡的组件与三卡布局、
“查看三级穿透”和“AI 改善建议”动作、8 个经营流程节点及其状态／摘要／跳转配置、“运营 360 整体分析”
标题入口。当前页面按原型尺寸保留这些位置为空，不使用风险列表或普通指标卡近似替代。因此首页不能
宣称已由交付元数据全量还原。

### 原型自身冲突（不擅自修正）

- 订未发同时出现 `44.6／39.6／45.0` 亿元，并混有 2025／2026 日期；各区域保留原文，不能强行相加。
- 团队目标存在 `90／91`、`73／72` 等差异；未来月份是原型预测，不是实绩。
- 出货电量按 `319 亿元 = 91 GWh` 的模拟比例折算；产品部月度数据按原型分配公式生成，不是真实逐产品部统计。
