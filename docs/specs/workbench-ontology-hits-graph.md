# 本体内容：命中本体关系图

用户希望命中本体有层级和关系，便于查找，复用现有 OntologyGraph。

- 本体内容概览只显示当前会话命中节点，复用 `@boulderaitech/ontology-graph` 的语义聚类、缩放、悬停高亮和对象归属布局。context 只提供命中节点之间的真实直接关系，不补入未命中节点。
- 点击命中节点后，在现有详情弹层显示该节点的关联上下文。概览不把未命中的中间节点折算成虚假直连；缺失关系时保留孤立命中节点。
- 本地类型与远端类型统一；按来源、本体库、类型、编码识别节点，重叠子图合并，同编码不同库不混淆。保留不同关系类型与方向。
- 原类型筛选作用于命中节点，删除悬空边。点击图中节点进入原本体图弹层。按用户最终决定，图内右上角只保留一个重置视图按钮，不提供搜索框、选择框、查看本体或独立重试按钮；部分请求失败时重置视图会重试失败项。
- 进入页面才查询关系，最多四个并发请求；离开页面中止未完成请求并同步释放渲染器。会话/数据源范围内缓存已成功的上下文，切换会话或数据源重新查询。
- 请求失败可重试；数据截断或关系不可用明确提示；WebGL 不可用时回退原列表，保持详情入口。
- 原命中卡片继续作为历史快照的数据载体，图画布独立于快照区域，不保存 canvas HTML，不改写历史文件。

主要文件：`frontend/src/ontologyHitsGraph.js`、`ontologyHitsGraphModel.js`、`runtime.js`、`shell.html`、`workbench.css`。
