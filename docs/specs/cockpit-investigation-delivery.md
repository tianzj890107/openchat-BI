# 原因未确认时的可执行核查交付（2026-11-02）

商机、订单、发货、共同分析在有可定位事实（带ID且非空值的facts，或带原始data的记录）时，不允许仅因根因未确认而交付空建议。交付工具会返回可修复的校验反馈，要求主服务同一轮补交至少一项有对象、证据及可检查验收的investigation。原因可为空，有依据的hypothesis明确标注并保留；订单风险和签单说明允许待验证假设，逐订单表格不因此允许套用环节假设。

不自动填固定核查模板、不编造订单或人员、不把假设升级为已核实根因、不为缺失值补零。remediation仍要求记录支持。核查动作可直接引用证据，无需causeIds；草稿链路沿用现有按选择集合生成的核查任务契约。责任与期限保持待确认。

报价及投标状态说明不强制建议，完全无事实也不强制。模型可能仍因超时或证据不够无法完整交付，因此不能承诺必有已证实根因。该修改在后续分析/预热时生效，不改写历史，不触发全量重算；已有空建议需在部署后定向重新分析。当前任务未部署。
