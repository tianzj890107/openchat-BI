# 智能分析 v0.1.0

## 基本信息

- 版本：`v0.1.0`
- 日期：`2026-08-28`
- 状态：正式版 / 当前版本
- Git Tag：`v0.1.0`
- 定版 commit：以 `v0.1.0` annotated tag 指向的 commit 为准

## 版本概述

openchat-BI（产品名“智能分析”）首个完整可用版本：基于 open-claude 的单 Agent +
本体知识库 + 工具循环架构，提供 Web 工作台（`bi-agent-web`）与对话式 BI 分析。
覆盖意图识别、本体模型匹配、深度思考与分析规划、数据获取和可视化、根因分析、
决策行动六个 SOP 阶段，支持 SQL/指标配置两类取数路径、表格图表生成、AskUser 澄清、
结构化 Claims 校验、根因与行动建议交付，以及历史会话恢复和报表模式。

## 核心能力

- 六步分析 SOP 状态机（意图识别 / 本体模型匹配 / 深度思考&分析规划 / 数据获取和
  可视化 / 根因分析 / 决策行动），支持真实回退与循环、`skipped` 静态跳过态；
- 本体工具族：`Ontology-SemanticQuery`、`Ontology-TermDisambiguate`、
  `MetricCalculation`、`Ontology-RelationQuery`、`Ontology-EntityDescribe`、
  `Ontology-MetricQuery`、`Ontology-FactQuery`，以及 `Ontology-GraphContext` /
  `Ontology-GraphExpand` 上下文；
- 取数与可视化：
  - `MetricCalculation`：获取指标定义、业务公式、统计口径、SQL 组件和适用维度；
  - `Ontology-MetricQuery`：通过远程本体的指标配置查询接口计算指标数据，已获得指标
    编码和维度编码时优先使用；
  - `Ontology-FactQuery`：执行只读事实查询或自主 SQL，当指标配置接口不支持、失败，
    或需要核验底层明细时使用；
  - `TableGenerate`：根据已有真实查询结果生成表格；
  - `ChartGenerate`：根据已有真实查询结果生成图表；
  - `ChartGenerateMultiDim`：根据已有多维查询结果生成多维图表；
  - 数据表结构类：`ListTables` / `DescribeTable`；
  - 看板表格与图表、结论卡片；
- 请求生命周期：SSE 流式输出、turn_id/generation 并发隔离、`session_superseded`、
  `done`/`error`/`stream_interrupted` 终态、done 幂等与失败防翻转；
- 质量与交付：结构化 Claims 校验与候选稿缓冲、行动建议补写（repair 阶段不执行
  工具）、`action_recommendations` 单次交付、根因/行动卡片仅停留对话区；
- Team 模型 thinking 能力表（已验证模型列表）与中文可见思考约束、turn 级自动
  fallback（不持久化用户模型选择）；
- 会话并发治理（409/429、进程内队列）、历史会话恢复与旧 SOP 展示兼容。

## 用户可见变化

- 左上角品牌统一为“智能分析”，产品显示版本 `v0.1.0`（`bi-analyst` 不再冒充版本）；
- HTML title、加载骨架、aria-label 与 React 工作台品牌一致；
- 六步 SOP 终态只把实际访问的步骤标为完成，未执行步骤显示静态 `skipped`，最终
  回答完成前不会六步全绿；
- SSE 无后端 `done` 时按“生成中断”处理，不伪装成功、不保存不完整回答；
- 行动建议补写阶段不再产生悬空工具卡片。

## 可靠性与数据安全

- 历史会话、上传文件、图表、日志等用户数据目录受 AGENTS.md 永久保护，禁止删除、
  清空、迁移或覆盖；
- 历史会话恢复只做展示层兼容映射，不重写旧会话 JSON；
- 自动 fallback 只影响当前 turn，不修改用户模型选择、全局配置或默认模型；
- Claims 校验失败不阻止最终正文输出，不新增回答门禁。

## 兼容性

- 历史五步、六步、九步 SOP 快照在展示层兼容恢复为当前六步；
- 会话 schema 版本（数值）与产品版本相互独立；
- 旧 `TEAM_ENABLE_THINKING` 仅作为 DeepSeek 兼容项保留。

## 验证情况

- 全量 Python 测试通过（当前分支最新状态）；
- 前端 Node 纯函数测试通过（SOP 状态机、EOF 分类、turn lifecycle、双远端脚本）；
- 前端 production build 成功；
- `git diff --check` 通过。

## 已知限制

- ChatBI 并发治理当前只支持单 Uvicorn worker，多 worker 需引入共享状态；
- L1/L2 简单查询不进入根因分析，第 5 步显示为跳过（属设计行为）；
- 部分外部依赖（远程本体服务、Doris、团队网关）在生产环境验证。

## 升级说明

- 从更早版本升级需重新构建前端产物并同步
  `bi_agent/web/static/vendor/antd/workbench.js` 与
  `bi_agent/web/static/vendor/antd/openchat-bi-workbench.css`；
- Agent 定义、后端 Schema 与前端构建产物需同步发布，历史会话迁移需先完整备份
  `dataset/conversations/`。
