    ⚙ 模型参数
    单次响应的最大输出 token 数,范围 256–200000。
    0 最确定性,1 平衡,2 最发散。Qwen 建议 ≤1.2。
    开启后模型会先输出推理过程再给最终回答。仅对支持思考模式的模型生效; Claude 模型在启用思考时会自动锁定 temperature=1.0。
    API 密钥
    用于 Claude Opus/Sonnet 模型。也可设为环境变量 ANTHROPIC_API_KEY(优先级更高)。
    用于 Qwen 系列模型。也可设为环境变量 DASHSCOPE_API_KEY。
    用于 DeepSeek V4 系列模型。也可设为环境变量 DEEPSEEK_API_KEY。
